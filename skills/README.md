# Skills

This directory contains reusable distributable specifications and reference material.

## Boundary

This directory is not the source of truth for Fongap Labs organization-wide agent behavior or engineering governance.

Organization-wide Agent Skills live in:

- [fongap-labs/action-worker/skills](https://github.com/fongap-labs/action-worker/tree/main/skills)

Keep content here only when it is a reusable public asset that can be consumed independently, such as a UI implementation specification or reference prompt.

Do not place shared bug-fix, CI diagnosis, review, release, governance, or general agent-execution rules here.
